# Mobile Rollout Monitoring Dashboard

## Dashboard Preview

![Mobile Rollout Monitoring Dashboard](./Mobile%20Rollout%20Monitoring%20Dashboard.png)

## Project Overview

An interactive Power BI dashboard designed to monitor mobile network rollout progress across multiple regions.

The dashboard provides an overview of project milestones, planned versus actual units, completion rates, and milestone statuses to support performance monitoring and data-driven decision-making.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset Overview

The dataset contains:

- 300 rollout milestones
- 60 sites
- 5 regions
- Planned and actual rollout units
- Milestone dates and statuses
- Responsible teams and priorities

## Key Performance Indicators (KPIs)

- Total Milestones
- Completed Milestones
- Blocked Milestones
- In Progress Milestones
- Not Started Milestones
- Completion Rate
- Remaining Units

## Dashboard Features

- Milestone status distribution
- Planned vs. actual units by region
- Planned vs. actual units over time
- Interactive filters by region, status, and month

## Data Preparation & Modeling

- Data cleaning and transformation using Power Query.
- Data type validation.
- Relationship creation between rollout, region, and calendar tables.
- DAX measures for KPIs and performance calculations.
